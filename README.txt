MON JOURNAL V1.0

1. Décompresser l'archive.
2. Déposer les fichiers à la racine d'un dépôt GitHub public ou privé avec hébergement HTTPS (par exemple GitHub Pages pour un dépôt public).
3. Activer Pages : Settings > Pages > Deploy from a branch > main / root.
4. Ouvrir l'adresse HTTPS sur Safari iPhone > Partager > Sur l'écran d'accueil.

IMPORTANT : GitHub Pages héberge le code, pas les observations. Les données sont stockées localement dans le navigateur sur l'appareil. Aucune connexion ni chiffrement applicatif ni synchronisation. Ne pas confondre avec un coffre-fort sécurisé. Les données peuvent disparaître lors d'un nettoyage de Safari ou changement d'appareil. Exporter fréquemment les sauvegardes JSON et les protéger.
